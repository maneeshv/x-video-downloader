# x-downloader

Bookmark a video on X/Twitter → it shows up in your own cloud storage a little later.
Runs entirely on Cloudflare, designed to cost ~$0/month for personal use.

Status: **design phase — no product code yet.** See `docs/STATUS.md`.

start with `CLAUDE.md`. If you are a human, start with `docs/PRODUCT.md`.
