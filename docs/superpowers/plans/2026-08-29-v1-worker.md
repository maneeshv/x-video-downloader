# x-downloader v1 Worker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One Cloudflare Worker that, every 30 minutes, reads the owner's X bookmarks via the official API v2, records every bookmark in D1, streams new videos into R2, and serves them on an Access-gated page.

**Architecture:** Single Worker (ADR-0008): `scheduled()` runs `sync()`; `fetch()` serves `/`, `/v/:key`, `/status`, `/oauth/*`, `/backfill`. R2 object key = download ledger (ADR-0003); D1 `bookmarks` table = index of every bookmark seen (ADR-0007); KV = tokens/status/pause. No framework, no queue, no ORM.

**Tech Stack:** TypeScript on Workers (`wrangler` 4.x), Node 25 built-in `node --test` with native type stripping, `node:sqlite` as the D1 test double, WebCrypto for PKCE + Access JWT verification. Only dev-dependencies: `wrangler`, `typescript`.

**Spec:** `docs/superpowers/specs/2026-08-29-x-downloader-design.md` (APPROVED 2026-08-29). Decisions: ADR-0002…0008. Facts: `docs/research/2026-08-29-x-api-v2.md`, `docs/GOTCHAS.md`.

## Global Constraints

- Never commit secrets; `.env`, `.dev.vars`, `wrangler.toml` are gitignored; `wrangler.toml.example` is committed (spec §4, hard rule 1).
- Absolute imports only: `import … from "#src/<file>"` (package.json `imports`; works in Node and wrangler's esbuild). No relative imports between `src/` files.
- No new runtime dependency (ADR-0006). Dev-deps allowed: `wrangler`, `typescript`.
- Hard caps are constants in `src/limits.ts` with provenance comments (ADR-0005): `MAX_API_REQUESTS_PER_RUN=3`, `MAX_DOWNLOADS_PER_RUN=5`, `MAX_FILE_BYTES=200 MB`, `STORAGE_ALERT_BYTES=9 GB`, backfill `max_results=90`, cap 800.
- Never log a token: only one helper builds `Authorization` headers; errors carry status + path only (spec §7).
- Bookmarks request exactly: `expansions=attachments.media_keys&media.fields=media_key,type,variants,preview_image_url,duration_ms&tweet.fields=created_at,text,attachments`. Never `author_id`/`user.fields` (spec §5).
- Every run processes every returned item; never stop at the first already-seen id (spec §4).
- Every code commit ships with `docs/JOURNAL.md` + `docs/STATUS.md` updates (`scripts/check-session.sh`). Absolute dates everywhere.
- Target ≤ ~550 lines in `src/` (spec said 500 before `access.ts` was added; note in JOURNAL if exceeded).
- `// ponytail:` comments mark deliberate ceilings; no `TODO`.

```ts
export const VERSION = "v1";
export const MAX_API_REQUESTS_PER_RUN = 3;          // cron run: 1 bookmarks page + ≤2 auth calls
export const MAX_DOWNLOADS_PER_RUN = 5;             // rest wait for the next tick (ADR-0008)
export const MAX_FILE_BYTES = 200 * 1024 * 1024;    // spec §5
export const BUFFER_IF_NO_LENGTH_BYTES = 100 * 1024 * 1024; // R2.put needs a known length for streams
export const STORAGE_ALERT_BYTES = 9 * 1024 ** 3;   // alert, keep downloading (owner default Q6)
export const PAUSE_MS_AUTH = 24 * 3600_000;         // 401/403 → pause 24 h
export const REFRESH_AHEAD_MS = 5 * 60_000;         // refresh when < 5 min left (access token lives 2 h)
export const PAGE_SIZE = 20;                        // per cron run
export const BACKFILL_PAGE_SIZE = 90;               // >90 breaks next_token — devcommunity.x.com/t/257339
export const BACKFILL_MAX_ITEMS = 800;              // X returns at most the 800 most recent bookmarks
export const BACKFILL_MAX_REQUESTS = 10;            // 800/90 = 9 pages
export const STALE_PARSER_RUNS = 30;                // consecutive runs with results but zero media → alert
export const DOWNLOAD_JITTER_MS: readonly [number, number] = [1000, 2000];
export const VIDEO_KEY_RE = /^\d{5,25}(-\d{1,2})?\.mp4$/;

// X API v2 — docs.x.com/x-api/users/get-bookmarks, docs.x.com/fundamentals/authentication/oauth-2-0/authorization-code
export const X_AUTHORIZE_URL = "https://x.com/i/oauth2/authorize";
export const X_TOKEN_URL = "https://api.x.com/2/oauth2/token";
export const X_API = "https://api.x.com/2";
export const X_SCOPES = "bookmark.read tweet.read users.read offline.access";
// No author_id / user.fields: may bill as $0.01 user reads (docs/research/2026-08-29-x-api-v2.md)

  "expansions=attachments.media_keys&media.fields=media_key,type,variants,preview_image_url,duration_ms&tweet.fields=created_at,text,attachments";
```

- [ ] **Step 4: Write the parsing half of `src/x.ts`**

```ts
export type Variant = { bit_rate?: number; content_type: string; url: string };
export type Media = { media_key: string; type: "video" | "animated_gif" | "photo"; variants?: Variant[]; preview_image_url?: string };
export type Tweet = { id: string; text: string; created_at?: string; attachments?: { media_keys?: string[] } };
export type BookmarksResponse = {
  data?: Tweet[];
  includes?: { media?: Media[] };
  meta?: { result_count?: number; next_token?: string };
  errors?: unknown[];
};
export type Video = { key: string; url: string; bitRate: number };
export type Item = {
  postId: string; text: string; postedAt: string | null; postUrl: string;
  previewUrl: string | null; hasVideoMedia: boolean; videos: Video[];
};

export function selectVariant(variants: Variant[] | undefined): Variant | null {
  const mp4 = (variants ?? []).filter((v) => v.content_type === "video/mp4");
  if (mp4.length === 0) return null;
  return mp4.reduce((best, v) => ((v.bit_rate ?? 0) > (best.bit_rate ?? 0) ? v : best));
}

export function parseBookmarks(res: BookmarksResponse): Item[] {
  const media = new Map((res.includes?.media ?? []).map((m) => [m.media_key, m]));
  return (res.data ?? []).map((t) => {
    const vids = (t.attachments?.media_keys ?? [])
      .map((k) => media.get(k))
      .filter((m): m is Media => !!m && (m.type === "video" || m.type === "animated_gif"));
    const videos = vids.flatMap((m, i) => {
      const v = selectVariant(m.variants);
      if (!v) return [];
      const key = vids.length > 1 ? `${t.id}-${i + 1}.mp4` : `${t.id}.mp4`;
      return [{ key, url: v.url, bitRate: v.bit_rate ?? 0 }];
    });
    return {
      postId: t.id, text: t.text, postedAt: t.created_at ?? null,
      postUrl: `https://x.com/i/status/${t.id}`,
      previewUrl: vids[0]?.preview_image_url ?? null,
      hasVideoMedia: vids.length > 0, videos,
    };
  });
}
```

```ts
export type Scripted = { status: number; body?: unknown; headers?: Record<string, string>; bodyBytes?: Uint8Array };
export type FakeFetch = typeof fetch & { calls: [string, RequestInit][] };

export function fakeFetch(script: Scripted[] | ((url: string, init: RequestInit) => Scripted)): FakeFetch {
  const calls: [string, RequestInit][] = [];
  const f = (async (input: string | URL | Request, init: RequestInit = {}) => {
    const url = typeof input === "string" ? input : input instanceof URL ? input.toString() : input.url;
    calls.push([url, init]);
    const s = typeof script === "function" ? script(url, init) : script.shift();
    if (!s) throw new Error(`fakeFetch: no scripted response for ${url}`);
    const headers = new Headers(s.headers ?? {});
    if (s.bodyBytes) return new Response(s.bodyBytes, { status: s.status, headers });
    if (!headers.has("content-type")) headers.set("content-type", "application/json");
    return new Response(s.body === undefined ? null : JSON.stringify(s.body), { status: s.status, headers });
  }) as FakeFetch;
  f.calls = calls;
  return f;
}
```

```ts
import { BOOKMARK_QUERY, X_API, X_AUTHORIZE_URL, X_SCOPES, X_TOKEN_URL } from "#src/limits";

export type Fetch = typeof fetch;
export type OAuthCfg = { clientId: string; clientSecret: string; redirectUri: string };
export type Tokens = { access: string; refresh: string; prevRefresh?: string; expiresAt: number };

export class XApiError extends Error {
  constructor(public status: number, public path: string, public rateLimitReset?: number) {
    super(`X API ${status} on ${path}`);
  }
}

const b64url = (bytes: Uint8Array): string =>
  btoa(String.fromCharCode(...bytes)).replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, "");

export function randomToken(bytes = 32): string {
  return b64url(crypto.getRandomValues(new Uint8Array(bytes)));
}

export async function pkceChallenge(verifier: string): Promise<string> {
  const digest = await crypto.subtle.digest("SHA-256", new TextEncoder().encode(verifier));
  return b64url(new Uint8Array(digest));
}

export function authorizeUrl(cfg: OAuthCfg, state: string, challenge: string): string {
  const u = new URL(X_AUTHORIZE_URL);
  const p: Record<string, string> = {
    response_type: "code", client_id: cfg.clientId, redirect_uri: cfg.redirectUri, scope: X_SCOPES,
    state, code_challenge: challenge, code_challenge_method: "S256",
  };
  for (const [k, v] of Object.entries(p)) u.searchParams.set(k, v);
  return u.toString();
}

// The only place a bearer token is turned into a header. Never log the result.
function bearer(access: string): Record<string, string> {
  return { Authorization: `Bearer ${access}` };
}

async function tokenRequest(f: Fetch, cfg: OAuthCfg, form: Record<string, string>, now: number): Promise<Tokens> {
  const res = await f(X_TOKEN_URL, {
    method: "POST",
    headers: { Authorization: "Basic " + btoa(`${cfg.clientId}:${cfg.clientSecret}`), "Content-Type": "application/x-www-form-urlencoded" },
    body: new URLSearchParams(form).toString(),
  });
  if (!res.ok) throw new XApiError(res.status, "/2/oauth2/token");
  const j = (await res.json()) as { access_token: string; refresh_token: string; expires_in: number };
  return { access: j.access_token, refresh: j.refresh_token, expiresAt: now + j.expires_in * 1000 };
}

export function exchangeCode(f: Fetch, cfg: OAuthCfg, code: string, verifier: string, now = Date.now()): Promise<Tokens> {
  return tokenRequest(f, cfg, { grant_type: "authorization_code", code, code_verifier: verifier, redirect_uri: cfg.redirectUri, client_id: cfg.clientId }, now);
}

export async function refreshTokens(f: Fetch, cfg: OAuthCfg, refresh: string, now = Date.now()): Promise<Tokens> {
  const t = await tokenRequest(f, cfg, { grant_type: "refresh_token", refresh_token: refresh, client_id: cfg.clientId }, now);
  return { ...t, prevRefresh: refresh };
}

async function apiGet<T>(f: Fetch, access: string, path: string): Promise<T> {
  const res = await f(`${X_API}${path}`, { headers: bearer(access) });
  if (!res.ok) {
    const reset = res.headers.get("x-rate-limit-reset");
    throw new XApiError(res.status, path.split("?")[0], reset ? Number(reset) : undefined);
  }
  return (await res.json()) as T;
}

export async function fetchMe(f: Fetch, access: string): Promise<string> {
  const j = await apiGet<{ data: { id: string } }>(f, access, "/users/me");
  return j.data.id;
}

export function fetchBookmarks(f: Fetch, access: string, userId: string, o: { maxResults: number; paginationToken?: string }): Promise<BookmarksResponse> {
  const q = new URLSearchParams(BOOKMARK_QUERY);
  q.set("max_results", String(o.maxResults));
  if (o.paginationToken) q.set("pagination_token", o.paginationToken);
  return apiGet<BookmarksResponse>(f, access, `/users/${userId}/bookmarks?${q}`);
}
```

```ts
import type { Tokens } from "#src/x";

export type BookmarkStatus = "no_video" | "pending" | "downloaded" | "failed";
export type BookmarkRow = {
  post_id: string; first_seen_at: string; posted_at: string | null; text: string | null; post_url: string;
  has_video: 0 | 1; status: BookmarkStatus; error: string | null; r2_key: string | null; bytes: number | null;
  preview_url: string | null; updated_at: string;
};
export type BookmarkUpsert = Omit<BookmarkRow, "first_seen_at" | "updated_at"> & { now: string };
export type Status = {
  lastRun?: string; lastError?: string | null; auth?: "ok" | "needs_reauth"; counts?: Record<string, number>;
  totalBytes?: number; noMediaRuns?: number; alerts?: Record<string, string>;
};
export type VideoMeta = { postId: string; text: string; postUrl: string; postedAt: string | null; previewUrl: string | null; bitRate: number };

// R2 head(key) is the download truth (ADR-0003); D1 is the index (ADR-0007); KV is small mutable state.
const UPSERT = `INSERT INTO bookmarks (post_id, first_seen_at, posted_at, text, post_url, has_video, status, error, r2_key, bytes, preview_url, updated_at)
VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
ON CONFLICT(post_id) DO UPDATE SET
  status      = CASE WHEN bookmarks.status = 'downloaded' THEN 'downloaded' ELSE excluded.status END,
  error       = CASE WHEN bookmarks.status = 'downloaded' THEN bookmarks.error ELSE excluded.error END,
  r2_key      = COALESCE(excluded.r2_key, bookmarks.r2_key),
  bytes       = COALESCE(excluded.bytes, bookmarks.bytes),
  preview_url = COALESCE(excluded.preview_url, bookmarks.preview_url),
  posted_at   = COALESCE(excluded.posted_at, bookmarks.posted_at),
  text        = COALESCE(excluded.text, bookmarks.text),
  has_video   = MAX(bookmarks.has_video, excluded.has_video),
  updated_at  = excluded.updated_at`;

export class Store {
  constructor(readonly kv: KVNamespace, readonly db: D1Database, readonly r2: R2Bucket) {}

  getTokens(): Promise<Tokens | null> { return this.kv.get<Tokens>("oauth", "json"); }
  putTokens(t: Tokens): Promise<void> { return this.kv.put("oauth", JSON.stringify(t)); }
  clearTokens(): Promise<void> { return this.kv.delete("oauth"); }
  getUserId(): Promise<string | null> { return this.kv.get("userId"); }
  putUserId(id: string): Promise<void> { return this.kv.put("userId", id); }

  async getStatus(): Promise<Status> { return (await this.kv.get<Status>("status", "json")) ?? {}; }
  async patchStatus(p: Partial<Status>): Promise<Status> {
    const s = { ...(await this.getStatus()), ...p };
    await this.kv.put("status", JSON.stringify(s));
    return s;
  }
  async getPausedUntil(): Promise<number> { return Number(await this.kv.get("paused_until")) || 0; }
  pause(untilMs: number): Promise<void> { return this.kv.put("paused_until", String(untilMs)); }
  clearPause(): Promise<void> { return this.kv.delete("paused_until"); }

  putPkce(state: string, verifier: string): Promise<void> { return this.kv.put(`pkce:${state}`, verifier, { expirationTtl: 600 }); }
  async takePkce(state: string): Promise<string | null> {
    const v = await this.kv.get(`pkce:${state}`);
    if (v) await this.kv.delete(`pkce:${state}`);
    return v;
  }

  async upsertBookmark(r: BookmarkUpsert): Promise<void> {
    await this.db.prepare(UPSERT)
      .bind(r.post_id, r.now, r.posted_at, r.text, r.post_url, r.has_video, r.status, r.error, r.r2_key, r.bytes, r.preview_url, r.now)
      .run();
  }
  getBookmark(postId: string): Promise<BookmarkRow | null> {
    return this.db.prepare("SELECT * FROM bookmarks WHERE post_id = ?").bind(postId).first<BookmarkRow>();
  }
  async listDownloaded(limit = 500): Promise<BookmarkRow[]> {
    const { results } = await this.db
      .prepare("SELECT * FROM bookmarks WHERE status = 'downloaded' ORDER BY first_seen_at DESC, post_id DESC LIMIT ?")
      .bind(limit).all<BookmarkRow>();
    return results;
  }

  async has(key: string): Promise<boolean> { return (await this.r2.head(key)) !== null; }
  async putVideo(key: string, body: ReadableStream | ArrayBuffer, meta: VideoMeta, contentType = "video/mp4"): Promise<void> {
    const customMetadata = Object.fromEntries(Object.entries(meta).map(([k, v]) => [k, v === null ? "" : String(v)]));
    await this.r2.put(key, body, { httpMetadata: { contentType }, customMetadata });
  }
  getVideo(key: string, reqHeaders: Headers): Promise<R2ObjectBody | R2Object | null> {
    return this.r2.get(key, { range: reqHeaders, onlyIf: reqHeaders });
  }
}
```

```ts
  const kp = await crypto.subtle.generateKey({ name: "RSASSA-PKCS1-v1_5", modulusLength: 2048, publicExponent: new Uint8Array([1, 0, 1]), hash: "SHA-256" }, true, ["sign", "verify"]);

      return `${signing}.${Buffer.from(sig).toString("base64url")}`;
```

```ts
import type { Fetch } from "#src/x";

type Jwk = JsonWebKey & { kid?: string };
// ponytail: module-level JWKS cache keyed by team domain; a Worker isolate is short-lived, 10 min is plenty.
const cache = new Map<string, { keys: Jwk[]; at: number }>();
const TTL_MS = 10 * 60_000;

const decode = (s: string): Uint8Array =>
  Uint8Array.from(atob(s.replace(/-/g, "+").replace(/_/g, "/").padEnd(s.length + ((4 - (s.length % 4)) % 4), "=")), (c) => c.charCodeAt(0));
const json = <T>(s: string): T => JSON.parse(new TextDecoder().decode(decode(s))) as T;

async function keys(f: Fetch, team: string, kid: string, now: number): Promise<Jwk> {
  let c = cache.get(team);
  for (let attempt = 0; attempt < 2; attempt++) {
    if (!c || now - c.at > TTL_MS || (attempt === 1)) {
      const res = await f(`${team}/cdn-cgi/access/certs`);
      if (!res.ok) throw new Error(`certs ${res.status}`);
      c = { keys: ((await res.json()) as { keys: Jwk[] }).keys, at: now };
      cache.set(team, c);
    }
    const k = c.keys.find((k) => k.kid === kid);
    if (k) return k;
  }
  throw new Error("unknown kid");
}

export async function verifyAccessJwt(f: Fetch, token: string, teamDomain: string, aud: string, now = Date.now()): Promise<{ email?: string }> {
  const [h, p, s] = token.split(".");
  if (!h || !p || !s) throw new Error("malformed token");
  const header = json<{ alg?: string; kid?: string }>(h);
  if (header.alg !== "RS256" || !header.kid) throw new Error("unsupported alg");
  const payload = json<{ aud?: string | string[]; iss?: string; exp?: number; email?: string }>(p);
  if (payload.iss !== teamDomain) throw new Error("iss mismatch");
  if (!(Array.isArray(payload.aud) ? payload.aud : [payload.aud]).includes(aud)) throw new Error("aud mismatch");
  if (!payload.exp || payload.exp * 1000 < now) throw new Error("exp");
  const jwk = await keys(f, teamDomain, header.kid, now);
  const key = await crypto.subtle.importKey("jwk", jwk, { name: "RSASSA-PKCS1-v1_5", hash: "SHA-256" }, false, ["verify"]);
  const ok = await crypto.subtle.verify("RSASSA-PKCS1-v1_5", key, decode(s), new TextEncoder().encode(`${h}.${p}`));
  if (!ok) throw new Error("bad signature");
  return { email: payload.email };
}
```

```ts
import {
  BACKFILL_MAX_ITEMS, BACKFILL_MAX_REQUESTS, BACKFILL_PAGE_SIZE, BUFFER_IF_NO_LENGTH_BYTES, DOWNLOAD_JITTER_MS,
  MAX_DOWNLOADS_PER_RUN, MAX_FILE_BYTES, PAGE_SIZE, PAUSE_MS_AUTH, REFRESH_AHEAD_MS, STALE_PARSER_RUNS, STORAGE_ALERT_BYTES,
} from "#src/limits";
import type { BookmarkStatus, BookmarkUpsert, Store } from "#src/store";
import { fetchBookmarks, parseBookmarks, refreshTokens, XApiError, type Fetch, type Item, type OAuthCfg, type Video } from "#src/x";

export type Cfg = OAuthCfg & { publicOrigin: string; telegram?: { token: string; chatId: string } };
export type Deps = { store: Store; fetch: Fetch; cfg: Cfg; now?: () => number; sleep?: (ms: number) => Promise<void>; random?: () => number };
export type SyncResult = { skipped?: "paused" | "needs_reauth"; error?: string; pages: number; seen: number; downloaded: number; failed: number; bytes: number };

const now = (d: Deps) => (d.now ?? Date.now)();
const iso = (ms: number) => new Date(ms).toISOString();

export async function alert(d: Deps, key: string, text: string): Promise<void> {
  const s = await d.store.getStatus();
  if (s.alerts?.[key]) return;
  await d.store.patchStatus({ alerts: { ...s.alerts, [key]: iso(now(d)) } });
  if (!d.cfg.telegram) return;
  const { token, chatId } = d.cfg.telegram;
  // https://core.telegram.org/bots/api#sendmessage
  await d.fetch(`https://api.telegram.org/bot${token}/sendMessage`, {
    method: "POST", headers: { "content-type": "application/json" },
    body: JSON.stringify({ chat_id: chatId, text: `x-downloader: ${text}` }),
  }).catch(() => undefined);
}

export async function clearAlert(d: Deps, key: string): Promise<void> {
  const s = await d.store.getStatus();
  if (!s.alerts?.[key]) return;
  const { [key]: _, ...rest } = s.alerts;
  await d.store.patchStatus({ alerts: rest });
}

// Refresh tokens are single-use and rotate (docs/GOTCHAS.md): persist the new pair BEFORE using it; fall back to prevRefresh once.
export async function ensureAccessToken(d: Deps, force = false): Promise<string | null> {
  const t = await d.store.getTokens();
  if (!t) return null;
  if (!force && t.expiresAt - now(d) > REFRESH_AHEAD_MS) return t.access;
  for (const r of [t.refresh, t.prevRefresh]) {
    if (!r) continue;
    try {
      const nt = await refreshTokens(d.fetch, d.cfg, r, now(d));
      if (r === t.prevRefresh) nt.prevRefresh = t.prevRefresh;
      await d.store.putTokens(nt);
      return nt.access;
    } catch (e) {
      if (!(e instanceof XApiError) || e.status >= 500) throw e;
    }
  }
  return null;
}

async function needsReauth(d: Deps, res: SyncResult): Promise<SyncResult> {
  await d.store.patchStatus({ auth: "needs_reauth", lastError: "needs_reauth", lastRun: iso(now(d)) });
  await d.store.pause(now(d) + PAUSE_MS_AUTH);
  await alert(d, "needs_reauth", `re-authorize at ${d.cfg.publicOrigin}/oauth/start`);
  return { ...res, skipped: "needs_reauth" };
}

function row(it: Item, status: BookmarkStatus, d: Deps, extra: Partial<BookmarkUpsert> = {}): BookmarkUpsert {
  return {
    post_id: it.postId, posted_at: it.postedAt, text: it.text, post_url: it.postUrl, has_video: it.hasVideoMedia ? 1 : 0,
    status, error: null, r2_key: it.videos[0]?.key ?? null, bytes: null, preview_url: it.previewUrl, now: iso(now(d)), ...extra,
  };
}

type Dl = { ok: true; bytes: number } | { ok: false; status: BookmarkStatus; error: string };

async function download(d: Deps, it: Item, v: Video): Promise<Dl> {
  const res = await d.fetch(v.url);
  if (!res.ok || !res.body) return { ok: false, status: res.status >= 500 ? "pending" : "failed", error: `http_${res.status}` };
  const len = Number(res.headers.get("content-length")) || 0;
  if (len > MAX_FILE_BYTES) return { ok: false, status: "failed", error: "too_large" };
  let body: ReadableStream | ArrayBuffer = res.body, bytes = len;
  if (!len) {
    // R2.put needs a known length for streams; buffer small unknown-length bodies, refuse big ones.
    const buf = await res.arrayBuffer();
    if (buf.byteLength > BUFFER_IF_NO_LENGTH_BYTES) return { ok: false, status: "failed", error: "no_length" };
    body = buf; bytes = buf.byteLength;
  }
  await d.store.putVideo(v.key, body, { postId: it.postId, text: it.text, postUrl: it.postUrl, postedAt: it.postedAt, previewUrl: it.previewUrl, bitRate: v.bitRate });
  return { ok: true, bytes };
}

async function processItem(d: Deps, it: Item, res: SyncResult, budget: { downloads: number }): Promise<void> {
  if (!it.hasVideoMedia) return d.store.upsertBookmark(row(it, "no_video", d));
  if (it.videos.length === 0) { res.failed++; return d.store.upsertBookmark(row(it, "failed", d, { error: "no_variants" })); }
  let bytes = 0, complete = true, fail: Dl | null = null;
  for (const v of it.videos) {
    const head = await d.store.r2.head(v.key);
    if (head) { bytes += head.size; continue; }
    if (budget.downloads >= MAX_DOWNLOADS_PER_RUN) { complete = false; continue; }
    budget.downloads++;
    const r = await download(d, it, v);
    if (r.ok) { bytes += r.bytes; res.downloaded++; res.bytes += r.bytes; }
    else { complete = false; fail = r; res.failed++; }
    const [lo, hi] = DOWNLOAD_JITTER_MS;
    await (d.sleep ?? ((ms) => new Promise((r) => setTimeout(r, ms))))(lo + (d.random ?? Math.random)() * (hi - lo));
  }
  if (complete) return d.store.upsertBookmark(row(it, "downloaded", d, { bytes }));
  if (fail && !fail.ok) return d.store.upsertBookmark(row(it, fail.status, d, { error: fail.error }));
  return d.store.upsertBookmark(row(it, "pending", d));
}

async function breaker(d: Deps, e: XApiError, res: SyncResult): Promise<SyncResult> {
  const t = now(d);
  if (e.status === 401) {
    const access = await ensureAccessToken(d, true);
    if (!access) return needsReauth(d, res);
  } else if (e.status === 429) {
    await d.store.pause(e.rateLimitReset ? e.rateLimitReset * 1000 : t + 15 * 60_000);
    await alert(d, "api_429", `rate limited, paused until ${iso(await d.store.getPausedUntil())}`);
  } else if (e.status === 403) {
    await d.store.pause(t + PAUSE_MS_AUTH);
    await alert(d, "api_403", `403 from X on ${e.path}; paused 24h. Check console.x.com credits/app.`);
  }
  await d.store.patchStatus({ lastRun: iso(t), lastError: e.message });
  return { ...res, error: e.message };
}

export async function sync(d: Deps, o: { backfill?: boolean } = {}): Promise<SyncResult> {
  const res: SyncResult = { pages: 0, seen: 0, downloaded: 0, failed: 0, bytes: 0 };
  if ((await d.store.getPausedUntil()) > now(d)) return { ...res, skipped: "paused" };
  const access = await ensureAccessToken(d);
  const userId = await d.store.getUserId();
  if (!access || !userId) return needsReauth(d, res);

  const maxPages = o.backfill ? BACKFILL_MAX_REQUESTS : 1;
  const pageSize = o.backfill ? BACKFILL_PAGE_SIZE : PAGE_SIZE;
  const budget = { downloads: 0 };
  let paginationToken: string | undefined, resultCount = 0, sawMedia = false;
  try {
    for (let page = 0; page < maxPages; page++) {
      const body = await fetchBookmarks(d.fetch, access, userId, { maxResults: pageSize, paginationToken });
      res.pages++;
      resultCount += body.meta?.result_count ?? 0;
      const items = parseBookmarks(body);
      res.seen += items.length;
      for (const it of items) {
        sawMedia ||= it.hasVideoMedia;
        await processItem(d, it, res, budget);
      }
      paginationToken = body.meta?.next_token;
      if (!paginationToken || res.seen >= BACKFILL_MAX_ITEMS) break;
    }
  } catch (e) {
    if (e instanceof XApiError) return breaker(d, e, res);
    throw e;
  }

  const s = await d.store.getStatus();
  const noMediaRuns = resultCount > 0 && !sawMedia ? (s.noMediaRuns ?? 0) + 1 : 0;
  if (noMediaRuns >= STALE_PARSER_RUNS) await alert(d, "stale_parser", `${noMediaRuns} runs with bookmarks but zero media — parser may be stale`);
  const totalBytes = (s.totalBytes ?? 0) + res.bytes;
  if (totalBytes > STORAGE_ALERT_BYTES) await alert(d, "storage", `stored ${(totalBytes / 1024 ** 3).toFixed(2)} GB (> 9 GB)`);
  await d.store.patchStatus({
    lastRun: iso(now(d)), lastError: null, auth: "ok", totalBytes, noMediaRuns,
    counts: { seen: res.seen, downloaded: res.downloaded, failed: res.failed, pages: res.pages },
  });
  for (const k of ["needs_reauth", "api_401", "api_403", "api_429"]) await clearAlert(d, k);
  return res;
}
```

```ts
import { verifyAccessJwt } from "#src/access";
import { renderIndex } from "#src/html";
import { VIDEO_KEY_RE } from "#src/limits";
import { Store } from "#src/store";
import { sync, type Deps } from "#src/sync";
import { authorizeUrl, exchangeCode, fetchMe, pkceChallenge, randomToken, type Fetch } from "#src/x";

export type AppEnv = {
  X_CLIENT_ID: string; X_CLIENT_SECRET: string; TELEGRAM_BOT_TOKEN?: string; TELEGRAM_CHAT_ID?: string;
  TEAM_DOMAIN: string; POLICY_AUD: string; PUBLIC_ORIGIN: string;
  VIDEOS: R2Bucket; KV: KVNamespace; DB: D1Database;
};

function deps(env: AppEnv, f: Fetch): Deps {
  return {
    store: new Store(env.KV, env.DB, env.VIDEOS), fetch: f,
    cfg: {
      clientId: env.X_CLIENT_ID, clientSecret: env.X_CLIENT_SECRET, redirectUri: `${env.PUBLIC_ORIGIN}/oauth/callback`, publicOrigin: env.PUBLIC_ORIGIN,
      telegram: env.TELEGRAM_BOT_TOKEN && env.TELEGRAM_CHAT_ID ? { token: env.TELEGRAM_BOT_TOKEN, chatId: env.TELEGRAM_CHAT_ID } : undefined,
    },
  };
}

const json = (o: unknown, status = 200) => new Response(JSON.stringify(o), { status, headers: { "content-type": "application/json" } });

async function video(store: Store, key: string, req: Request): Promise<Response> {
  if (!VIDEO_KEY_RE.test(key)) return new Response("not found", { status: 404 });
  const obj = await store.getVideo(key, req.headers);
  if (!obj) return new Response("not found", { status: 404 });
  const headers = new Headers();
  obj.writeHttpMetadata(headers);
  headers.set("etag", obj.httpEtag);
  headers.set("accept-ranges", "bytes");
  if (!("body" in obj)) return new Response(null, { status: 412, headers });
  const r = obj.range;
  if (r && "offset" in r && r.length !== undefined) {
    headers.set("content-range", `bytes ${r.offset}-${r.offset + r.length - 1}/${obj.size}`);
    headers.set("content-length", String(r.length));
    return new Response(obj.body, { status: 206, headers });
  }
  headers.set("content-length", String(obj.size));
  return new Response(obj.body, { status: 200, headers });
}

export async function handle(req: Request, env: AppEnv, f: Fetch = fetch): Promise<Response> {
  const url = new URL(req.url);
  // Every route, including the OAuth callback, sits behind Access (spec §4); the JWT check defends a misconfigured policy.
  const jwt = req.headers.get("cf-access-jwt-assertion");
  try { if (!jwt) throw new Error("missing"); await verifyAccessJwt(f, jwt, env.TEAM_DOMAIN, env.POLICY_AUD); }
  catch { return new Response("forbidden", { status: 403 }); }

  const d = deps(env, f);
  const { store } = d;
  if (req.method !== "GET") return new Response("method not allowed", { status: 405 });

  if (url.pathname === "/") return new Response(renderIndex(await store.listDownloaded(), await store.getStatus()), { headers: { "content-type": "text/html; charset=utf-8" } });
  if (url.pathname.startsWith("/v/")) return video(store, decodeURIComponent(url.pathname.slice(3)), req);
  if (url.pathname === "/status") return json({ ...(await store.getStatus()), pausedUntil: await store.getPausedUntil(), userId: await store.getUserId() });
  if (url.pathname === "/oauth/start") {
    const state = randomToken(16), verifier = randomToken(64);
    await store.putPkce(state, verifier);
    return Response.redirect(authorizeUrl(d.cfg, state, await pkceChallenge(verifier)), 302);
  }
  if (url.pathname === "/oauth/callback") {
    const code = url.searchParams.get("code"), state = url.searchParams.get("state");
    const verifier = state && (await store.takePkce(state));
    if (!code || !verifier) return new Response("bad state", { status: 400 });
    const tokens = await exchangeCode(f, d.cfg, code, verifier);
    await store.putTokens(tokens);
    await store.putUserId(await fetchMe(f, tokens.access));
    await store.clearPause();
    await store.patchStatus({ auth: "ok", lastError: null });
    return Response.redirect(`${env.PUBLIC_ORIGIN}/`, 302);
  }
  if (url.pathname === "/backfill") return json(await sync(d, { backfill: true }));
  return new Response("not found", { status: 404 });
}

export default {
  fetch: (req: Request, env: AppEnv) => handle(req, env),
  async scheduled(_c: ScheduledController, env: AppEnv, ctx: ExecutionContext) {
    ctx.waitUntil(sync(deps(env, fetch)));
  },
} satisfies ExportedHandler<AppEnv>;
```
