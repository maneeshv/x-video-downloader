# Gotchas

Curated, topic-grouped facts a future session could re-trip on. Not a log: JOURNAL is the log. Rules in `docs/STANDARDS.md` ("Gotchas lifecycle"). Each line: date learned, the fact, source, and where it is baked in (or "not yet"). Delete a line once code or a runbook encodes it.

## X API v2
- 2026-08-29: Bookmarks endpoint returns only the **800 most recent** bookmarks and every read is billed — anything not recorded when first seen may be unrecoverable. Source: `docs/research/2026-08-29-x-api-v2.md`. Baked into: ADR-0007; `src/limits.ts` (`BACKFILL_MAX_ITEMS`).
- 2026-08-29: Reads are deduplicated per 24 h UTC day per Post, so polling cadence barely affects cost (≈ $0.70/mo). The cheaper "Owned Reads" rate may **not** yet apply to bookmarks ($0.005 instead of $0.001) — check the first console usage report. Source: `docs/research/2026-08-29-x-api-v2.md`. Baked into: spec §6/§9; not verified in production yet.

## X media
- 2026-08-29: `video.twimg.com/*.mp4` URLs are fetchable **anonymously** (no auth), expose `Content-Length` and `Accept-Ranges`. Live-tested with curl. Source: `docs/research/2026-08-29-persona-x-scraper.md`. Baked into: `src/sync.ts` `download()` relies on it; not commented in code.
- 2026-08-29: `animated_gif` media variants shape is unverified; parser must tolerate absence. Source: spec §9. Baked into: not yet — watch `src/x.ts` `parseBookmarks`/`selectVariant` if a real `animated_gif` bookmark ever misparses.

## Cloudflare
- 2026-08-29: Workers **Free** plan CPU cap is **10 ms per invocation**. Streaming `fetch → R2.put` should be I/O-wait, but it is unspiked; Error 1102 means move to Workers Paid (owner approved, Q5). Source: https://developers.cloudflare.com/workers/platform/limits/#cpu-time. Baked into: spec §6/§9, ADR-0008; not verified against a real large download yet.
- 2026-08-29: The `cloudflare-docs` MCP (no auth) is a valid source for hard rule 5 alongside Context7. Baked into: `CLAUDE.md` rule 5.

## Tooling (Claude Code on this repo)
- 2026-09-11 Local UI fixtures served through production `/p/:id` retain immutable poster caching across preview-server restarts. Use fresh synthetic post IDs when replacing fixture image bytes; do not weaken production cache headers for a preview. Source: cinematic Library browser QA. Baked into: not yet.
- 2026-09-11 Sandboxed npm ci may report `Exit handler never called!` when network access is unavailable (curl also reported DNS failure); the same lockfile installed successfully with approved network access and a task-local npm cache. Do not treat that message alone as a repository dependency defect. Source: cinematic Library implementation. Baked into: not yet.
- 2026-09-02 Chrome browser control can time out repeatedly during authenticated `xrender.uk` verification while Wrangler and unauthenticated HTTP checks remain healthy; do not infer a bad deploy from the browser timeout or claim owner-path verification. Retry from a working signed-in browser session. Source: duration-repair and friend-access deploy sessions. Baked into: not yet.
- 2026-09-02 Parallel branches can independently allocate the same next ADR number. After fetching/merging `main`, keep the already-merged ADR number and renumber the incoming branch's ADR plus every reference before committing. Source: PR #20 and PR #21 both created ADR-0015; PR #21 became ADR-0016. Baked into: not yet.
- 2026-09-02 This Paseo worktree's Git metadata is under the primary checkout, outside the writable sandbox; index-writing commands such as `git add`/`commit` fail on `.git/worktrees/puny-dinosaur/index.lock` with `Operation not permitted`. Run them unsandboxed. Baked into: not yet.
- 2026-09-02 Homebrew FFmpeg 8.0.1 on this Mac lacks the `drawtext` filter (`No such filter: 'drawtext'`), so walkthrough captions need pre-rendered text or a caption-free render. Baked into: not yet.
- 2026-08-31 Any git command that writes `.claude/hooks/` (merge/checkout/pull of a commit touching it, e.g. ADR-0014's `session-protocol.sh`) fails inside the Claude Code sandbox with `cannot create directory at '.claude/hooks': Operation not permitted` — the path is on the sandbox write-deny list. Run that one git command with the sandbox disabled. Baked into: not yet (add to `docs/runbooks/agent-setup.md` next to the push/fetch note if it re-trips).
- 2026-08-31 `git push`/`fetch` over SSH fails inside the Claude Code sandbox with "correct access rights / repository exists" — it is the sandbox (blocked `~/.ssh` + outbound SSH via the `github.com-personal` alias), not the remote. Push unsandboxed on the first try. Baked into: `docs/runbooks/agent-setup.md` step 5 — delete this line once two sessions have pushed without tripping it.
- 2026-08-30 Gitignored `wrangler.toml` drifts between git worktrees (Paseo copies it from the main checkout at worktree creation). Deploying from a worktree with a stale copy silently re-enabled workers.dev and reverted `PUBLIC_ORIGIN`. Diff it against `wrangler.toml.example` before every deploy. Baked into: `docs/runbooks/deploy.md` "Before every deploy" — delete this line once that check has caught nothing for two deploys. Re-tripped 2026-08-31 in two worktrees created before this step existed (one deployed stale, one caught it with the pre-check); the copy source `/Users/maneesh/Developer/personal-project/x-downloader/wrangler.toml` was still stale (no `[[routes]]`, workers.dev `PUBLIC_ORIGIN`) — until the owner updates that file, every new Paseo worktree starts stale. Tripped a **third** time 2026-08-31 and a **fourth** time 2026-09-02; both pre-checks caught it before deploy. Delete this line once the main checkout copy matches the example.
- 2026-08-30 `curl` inside the Claude Code Bash sandbox goes through the egress proxy: a blocked host shows up as `HTTP/1.1 502 Bad Gateway` or `HTTP/1.1 200 Connection Established`, which look like real answers. Any status-code verification of a deployed URL must run with `dangerouslyDisableSandbox`. Baked into: `docs/runbooks/agent-setup.md` step 5 (2026-08-31) — delete this line once two sessions have verified a deploy without tripping it.
- 2026-08-30: `node --test` shares one module graph per test FILE, so module-level caches (e.g. the JWKS cache in src/access.ts) persist across test() blocks — use distinct cache keys (random `kid`/team domain) per test. Baked into: test/index.test.ts, test/access.test.ts.
- 2026-08-30 Workers `fetch` throws `Illegal invocation` when called as a method of another object (`deps.fetch(url)`); wrap it in an arrow. Baked into: `src/index.ts` `deps()` comment + `test/index.test.ts` bound-`this` assertion — delete this line once you trust the test.
- 2026-08-30 `R2Object.range` has all of `offset`/`length`/`suffix` as keys (unused = `undefined`); never discriminate with `"suffix" in r`. Baked into: `src/index.ts` `servedRange()` comment + `FakeR2` shape in `test/fakes.ts`.
- 2026-08-30 `wrangler -c wrangler.toml.example` is silently ignored (extension must be .toml/.json/.jsonc); copy to `wrangler.toml` first. Baked into: `.github/workflows/check.yml` comment.
- 2026-08-30 To wipe R2: no `wrangler r2 object list`; derive keys from D1 `post_id` + the `<id>.mp4` / `<id>-n.mp4` scheme, or use rclone. `wrangler kv key put` needs the value as an argument, not stdin. Baked into: `docs/runbooks/reset-store.md` — delete this line once that runbook has been used twice.
- 2026-09-02 The sandbox blocks localhost listeners (`listen EPERM`) and Wrangler's log directory under `~/Library/Preferences/.wrangler`; `wrangler types` and temporary preview servers both work unsandboxed. Baked into: `docs/runbooks/agent-setup.md` step 5.
- 2026-08-31 All git worktrees of this repo share `.git` remote-tracking refs: a sibling session's `git fetch` silently moves `origin/main` (and other `origin/*`) under you mid-session, so re-check `git rev-parse origin/main` before writing STATUS facts about what is merged, and treat `git merge origin/main` → "Fast-forward" on a feature branch as "the owner merged this PR already". Seen 2026-08-31 during the four-way quick-win chaining (PRs #16 and #18 landed between two commands). Baked into: not yet — promote to a check in `scripts/check-session.sh` or the JOURNAL template if it re-trips.
- 2026-08-30 `git cherry-pick -q` is not a valid flag (fails immediately); a `set -e` shell chain that continues past that failure anyway can delete a branch before its commits were actually carried over — commits are still recoverable from their SHAs (`git log --all`/reflog) if this happens. Baked into: not yet — re-tripped once already (see the 2026-08-30 "v1 merged to `main`" and "Video library UI" JOURNAL entries); promote to a runbook/script check if it happens a third time.
